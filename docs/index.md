# CAMINO

!!! note "Placeholder landing page"
    This page will be expanded into a proper landing page for the project, including an overview of the package, links to the key workflows, and quick installation instructions.

CAMINO is a Python package for modelling and inferring wavefront aberrations from JWST/NIRCam observations.

## Why CAMINO?

It provides the tools needed to model optical systems, extract PSFs, manage exposure-level data, and fit wavefront aberration and defocus parameters from real observations.
